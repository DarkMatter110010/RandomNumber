# 抽号器 v6.2

这是一个基于 Python Tkinter 开发的桌面端随机抽号应用程序，专为课堂点名、抽奖等场景设计。软件支持自定义学号范围、权重概率设置以及窗口置顶功能。

## 📁 文件结构

在当前目录下，你将看到以下核心文件：

*   `抽号器v6.2.py`：主程序文件，直接运行即可启动应用。
*   `settings.json`：配置文件，存储窗口置顶、侧边栏等设置（程序运行后自动生成）。
*   `number.json`：数据文件，存储学号及其对应的抽取权重（程序运行后自动生成，默认包含 1~50）。

## 🚀 功能特性

*   **大屏显示**：抽中的号码会以超大字体显示在中央区域，方便展示。
*   **加权抽取**：支持修改每个学号的抽取概率（权重），数值越高被抽中的概率越大。
*   **范围自定义**：可自由修改起始和结束学号，适应不同班级规模。
*   **智能保存**：所有设置和学号权重在关闭后自动保存，下次启动无需重新配置。
*   **窗口置顶**：支持设置窗口始终在最前，方便配合投影仪使用。
*   **侧边栏最小化**：可设置关闭时最小化到屏幕侧边栏，避免误关。

## 🛠️ 使用说明

### 1. 运行程序
确保你的电脑已安装 Python 环境（需包含 tkinter 库），双击运行 `抽号器v6.2.py`。

### 2. 基本操作
*   **点击“抽号”**：开始随机抽取一个号码。
*   **点击“清空”**：清除当前显示的号码。
*   **菜单栏 > 文件 > 修改起末学号**：调整学号的起始和结束值（范围限制在 1~999）。
*   **菜单栏 > 文件 > 修改概率**：为每个学号设置不同的抽取权重（0~50）。

### 3. 设置选项
*   **置顶**：在“设置”菜单中勾选“置顶”，窗口将始终显示在最前面。
*   **侧边栏**：勾选“关闭时最小化到侧边栏”后，点击关闭按钮会将窗口缩小到屏幕右侧，点击箭头可恢复。

## 📂 数据文件说明

### `number.json`
该文件存储了学号与权重的映射关系。格式如下：
```json
{
  "1": 1,
  "2": 1,
  "3": 2
}
```
键为学号（字符串），值为权重（整数）。

### `settings.json`
该文件存储了用户的偏好设置。格式如下：
```json
{
  "top": true,
  "sidebar": true
}
```
* top: 布尔值，控制窗口是否置顶。
* sidebar: 布尔值，控制关闭时是否最小化到侧边栏。
